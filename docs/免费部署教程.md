# 免费部署教程（零成本上线）

本文档介绍如何利用免费云平台，**零成本**部署 POETIZE 博客系统。

## 适用场景

- 个人博客，访问量不大
- 零预算体验完整博客系统
- 学生/个人开发者快速上线

## 方案架构

```
┌─────────────┐     ┌──────────────┐     ┌───────────────────┐
│  用户浏览器   │────▶│  Vercel       │────▶│  Render / Koyeb    │
│             │     │  (前端 SPA)   │     │  (Java 后端)       │
└─────────────┘     └──────────────┘     └────────┬──────────┘
                                                   │
                              ┌─────────────────────┼──────────────┐
                              │                     │              │
                    ┌─────────▼──────┐   ┌──────────▼───┐  ┌──────▼──────┐
                    │ TiDB Cloud     │   │ Upstash      │  │ UptimeRobot │
                    │ (MySQL 数据库)  │   │ (Redis 缓存) │  │ (保活监控)   │
                    └────────────────┘   └──────────────┘  └─────────────┘
```

## 方案一：Render + TiDB + Upstash + Vercel（推荐，完全免费）

### 第一步：Fork 项目

1. 登录 [GitHub](https://github.com)
2. 打开 [awesome-poetize-open](https://github.com/LeapYa/awesome-poetize-open)
3. 点击右上角 **Fork** 按钮，Fork 到你自己的账号

### 第二步：创建 TiDB Cloud 数据库

[TiDB Cloud](https://tidbcloud.com/) 提供免费的 MySQL 兼容数据库。

1. 注册 [TiDB Cloud 账号](https://tidbcloud.com/free-trial)（无需信用卡）
2. 创建 **Starter** 集群（原 Serverless），选择离你最近的区域
3. 创建完成后，进入集群 → **Connect** → 获取连接信息：
   - Host: `gateway01.xxx.prod.aws.tidbcloud.com`
   - Port: `4000`
   - User: `your_user`
   - Password: `your_password`
   - Database: 建议创建一个名为 `poetize` 的数据库

4. 使用 MySQL 客户端连接并导入数据：

```bash
# 连接 TiDB（兼容 MySQL 客户端）
mysql -h gateway01.xxx.prod.aws.tidbcloud.com -P 4000 -u your_user -p --ssl-mode=VERIFY_IDENTITY

# 在 TiDB 控制台中创建数据库
CREATE DATABASE poetize;
USE poetize;

# 导入初始化 SQL（首次安装只需这一个文件）
source poetize-server/sql/poetry.sql;
```

> **提示**：TiDB Cloud 后台也提供 Web 版 SQL 编辑器，可以直接粘贴 SQL 执行。

**免费额度**：每个集群 5GiB 存储 + 5000 万 RUs/月，对个人博客完全足够。

### 第三步：创建 Upstash Redis

[Upstash](https://upstash.com/) 提供免费的 Serverless Redis。

1. 注册 [Upstash 账号](https://console.upstash.com/)（无需信用卡）
2. 创建 Redis 数据库，选择离后端最近的区域
3. 获取连接信息：
   - `UPSTASH_REDIS_REST_URL`
   - Host: `xxx.upstash.io`
   - Port: `6379`
   - Password: `your_redis_password`

**免费额度**：256MB 数据 + 50 万命令/月。

### 第四步：部署后端到 Render

> **说明**：当前仓库默认按 JVM 方式部署后端。Render 免费实例资源比较紧张，是否适合你的站点取决于访问量、功能开关和运行参数；如果运行中出现内存不足、冷启动过慢或频繁休眠，建议升级实例或改用自己的服务器 / VPS。

1. 注册 [Render 账号](https://dashboard.render.com/register)
2. 点击 **New** → **Web Service**
3. 连接你 Fork 的 GitHub 仓库
4. 在 Render 中配置：
   - **Name**：`poetize-backend`
   - **Region**：选择离你数据库最近的区域
   - **Runtime**：Docker
   - **Dockerfile Path**：`docker/java/Dockerfile`
   - **Instance Type**：**Free**

5. 添加环境变量：

| 变量名 | 值 | 说明 |
|--------|-----|------|
| `SERVER_PORT` | `8081` | 后端端口 |
| `SPRING_DATASOURCE_URL` | `jdbc:mysql://gateway01.xxx.prod.aws.tidbcloud.com:4000/poetize?useUnicode=true&characterEncoding=utf-8&useSSL=true&serverTimezone=Asia/Shanghai` | TiDB 连接 URL（注意用 `mysql` 而非 `mariadb`） |
| `SPRING_DATASOURCE_USERNAME` | TiDB 用户名 | |
| `SPRING_DATASOURCE_PASSWORD` | TiDB 密码 | |
| `SPRING_DATASOURCE_DRIVER_CLASS_NAME` | `com.mysql.cj.jdbc.Driver` | MySQL 驱动 |
| `DB_TYPE` | `mysql` | 数据库类型 |
| `SPRING_REDIS_HOST` | Upstash Host | |
| `SPRING_REDIS_PORT` | `6379` | |
| `SPRING_REDIS_PASSWORD` | Upstash 密码 | |
| `SITE_URL` | `https://your-site.vercel.app` | 你的前端域名 |
| `POETIZE_AES_KEY` | `sarasarasarasara` | AES 密钥（需与前端一致） |
| `TOKEN_SECRET_KEY` | 随机 32 位字符串 | Token 签名 |
| `RAG_ENABLED` | `false` | TiDB 不支持向量检索，需关闭 |

6. 点击 **Create Web Service**，等待部署完成

> **注意**：首次 Docker 构建可能需要较长时间，后续部署通常会因为缓存而更快。如果构建日志提示依赖下载慢，可以稍后重试，或在代码仓库中预先锁定依赖版本。

### 第五步：配置保活（防止冷启动）⭐

**这是关键步骤！** Render 免费实例闲置 15 分钟后会休眠，通过保活工具可以防止休眠。

####  方式一：UptimeRobot（推荐）

1. 注册 [UptimeRobot](https://uptimerobot.com/)（免费版支持 50 个监控）
2. 添加新监控：
   - **Monitor Type**：HTTP(s)
   - **Friendly Name**：Poetize Backend
   - **URL**：`https://your-backend.onrender.com/actuator/health`
   - **Monitoring Interval**：5 minutes
3. 保存，UptimeRobot 会每 5 分钟自动请求你的后端，保持服务常驻

#### 方式二：cron-job.org

1. 注册 [cron-job.org](https://cron-job.org/)
2. 创建新任务：
   - **URL**：`https://your-backend.onrender.com/actuator/health`
   - **Schedule**：Every 5 minutes
3. 保存激活

> **原理**：Render 免费版有 750 小时/月的实例时间（31.25 天），保活后 24/7 运行完全够用。只要每 15 分钟内有至少一次 HTTP 请求到达，实例就不会休眠。

### 第六步：部署前端到 Vercel

1. 注册 [Vercel 账号](https://vercel.com/)
2. 点击 **Import Project** → 选择你 Fork 的仓库
3. 配置：
   - **Framework Preset**：Vite
   - **Root Directory**：`poetize-web`
   - **Build Command**：`npm run build`
   - **Output Directory**：`dist`
4. 添加环境变量：
   - `VUE_APP_POETIZE_AES_KEY` = `sarasarasarasara`
5. 点击 **Deploy**

#### 配置 API 代理

在 `poetize-web/` 目录下创建 `vercel.json`：

```json
{
  "rewrites": [
    {
      "source": "/api/:path*",
      "destination": "https://your-backend.onrender.com/:path*"
    },
    {
      "source": "/user/:path*",
      "destination": "https://your-backend.onrender.com/user/:path*"
    },
    {
      "source": "/ws/:path*",
      "destination": "https://your-backend.onrender.com/ws/:path*"
    }
  ]
}
```

> **说明**：通过 Vercel 的 rewrites 功能将 API 请求代理到 Render 后端，避免跨域问题。

### 第七步：部署后台管理到 Vercel

再次在 Vercel 中导入同一仓库，但配置不同：

1. **Root Directory**：`poetize-admin`
2. **Build Command**：`npm run build`
3. **Output Directory**：`dist`
4. 添加同样的 `vercel.json` 代理配置

### 第八步：配置图床（必须）⭐

免费平台没有持久存储，上传的图片在服务重启后会丢失。**必须配置外部图床**来存储博客图片。

#### 方式一：七牛云（推荐，有免费额度）

[七牛云](https://www.qiniu.com/) 提供 10GB 免费存储 + 每月 10GB CDN 流量。

1. 注册 [七牛云账号](https://portal.qiniu.com/signup)（需实名认证）
2. 进入 **对象存储 Kodo** → **新建存储空间**
   - 空间名称：`poetize-images`（自定义）
   - 存储区域：选择离你最近的区域
   - 访问控制：**公开**
3. 获取密钥：右上角头像 → **密钥管理** → 记录 `AccessKey` 和 `SecretKey`
4. 绑定域名（可选）：七牛云提供测试域名，也可以绑定自己的 CDN 加速域名
5. 在博客后台管理中配置：
   - 进入 **系统管理** → **网站配置**
   - 存储类型选择 **七牛云**
   - 填入 AccessKey、SecretKey、Bucket 名称和域名

**免费额度**：10GB 标准存储 + 每月 10GB CDN 下行流量（HTTP），对个人博客完全足够。

#### 方式二：Cloudflare R2（备选，免费 10GB）

[Cloudflare R2](https://www.cloudflare.com/products/r2/) 提供 10GB 免费存储，无出站流量费。

1. 注册 [Cloudflare 账号](https://dash.cloudflare.com/sign-up)
2. 进入 **R2 对象存储** → **创建存储桶**
3. 创建 API Token（R2 读写权限）
4. 配置公共访问域名
5. 在后台管理中使用 **S3 兼容** 方式接入（R2 兼容 S3 API）

**免费额度**：10GB 存储 + 每月 1000 万次 A 类请求 + 无出站流量费。

> **注意**：Cloudflare R2 在国内访问速度较慢。如果你的读者主要在国内，推荐使用七牛云。

## SEO 预渲染限制说明

POETIZE 是 SPA（单页应用），搜索引擎爬虫（如 Google、百度）可能无法正确抓取 JavaScript 渲染的内容。预渲染将文章渲染为静态 HTML，让爬虫能直接读取，提升 SEO 收录。

本教程的主方案是 **Render / Koyeb 部署 Java 后端，Vercel 部署前端 SPA**。这类免费前后端分离部署中，Vercel 的静态文件目录和 Render / Koyeb 的 Java 容器文件系统并不共享，所以 Java 后端生成的 `prerender/` 文件不会自动出现在 Vercel CDN 上。

因此免费方案建议按默认方式部署前后端，先保证博客核心功能可用。免费方案默认不处理 SEO 预渲染；如果你非常在意搜索引擎收录，推荐改用 Docker 一键部署、裸机部署或宝塔部署，让 Java 后端、前端构建产物和 Nginx 共享同一份静态目录。

## 常见问题

### Q: 后端第一次访问很慢？

确认 UptimeRobot 保活是否配置成功。检查 UptimeRobot 面板中的监控状态，应显示"Up"。

如果开启了保活，首次访问明显变慢的情况通常会少很多；如果你仍然感觉恢复较慢，可以优先检查实例规格、健康检查配置和依赖服务的响应时间。

### Q: TiDB 和 MariaDB 有兼容性问题吗？

TiDB 高度兼容 MySQL 8.0 协议。本项目已支持 MySQL 配置（`DB_TYPE=mysql`），主要注意：
- 使用 `com.mysql.cj.jdbc.Driver` 而非 `org.mariadb.jdbc.Driver`
- 连接 URL 使用 `jdbc:mysql://` 而非 `jdbc:mariadb://`
- 需要关闭 RAG 向量检索（`RAG_ENABLED=false`），因为 TiDB 的向量功能与 MariaDB 不同

### Q: 上传的图片存在哪里？

免费方案的后端没有持久存储，**必须配置外部图床**。参见[第八步：配置图床](#第八步配置图床必须)，推荐使用七牛云（免费 10GB）。

### Q: WebSocket 聊天室能用吗？

Render 和 Koyeb 都支持 WebSocket，但可能有连接时长限制（通常 5-10 分钟无消息会断开）。聊天室的基本功能可用，但长时间挂机可能需要重连。

### Q: 免费额度用完了怎么办？

- **Render**：超过 750 小时/月会暂停服务，下月自动恢复。保活 24/7 运行约用 720 小时/月，在限额内
- **TiDB**：超过 5GiB 存储需付费（$0.20/GiB），个人博客很难超
- **Upstash**：超过 50 万命令/月按量计费，博客低流量不易超

### Q: 能不能用 Cloudflare Pages 代替 Vercel？

可以，但 Cloudflare Pages 在国内访问速度较慢。如果你的读者主要在海外，Cloudflare Pages 是不错的选择（无限带宽、免费 CDN）。
