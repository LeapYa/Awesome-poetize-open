# 裸机部署教程（不使用 Docker）

本文档介绍如何在 Linux 服务器上**不使用 Docker**，手动安装各组件来部署 POETIZE 博客系统。

## 适用场景

- 服务器不支持或不想安装 Docker
- 希望对每个组件有完全控制
- 学习了解项目各组件的工作原理

> **提示**：如果你的服务器支持 Docker，推荐使用一键脚本部署，参见 [README.md](../README.md)。

## 前提条件

| 项目 | 要求 |
|------|------|
| 服务器 | 2 核 CPU / 2GB 内存 / 20GB 磁盘（最低），推荐 4GB+ 内存 |
| 操作系统 | Ubuntu 22.04+、Debian 12+、CentOS 9+ |
| 域名 | 可选，上线需要绑定域名 |
| 网络 | 开放 80（HTTP）、443（HTTPS）端口 |

## 1. 安装基础环境

### 1.1 更新系统

```bash
# Ubuntu / Debian
sudo apt update && sudo apt upgrade -y

# CentOS / RHEL
sudo dnf update -y
```

### 1.2 安装 JDK 25

推荐使用 [SDKMAN](https://sdkman.io/) 安装，方便管理多版本：

```bash
# 安装 SDKMAN
curl -s "https://get.sdkman.io" | bash
source "$HOME/.sdkman/bin/sdkman-init.sh"

# 安装 JDK 25（查看可用版本：sdk list java）
sdk install java 25.0.2-open

# 验证
java -version
```

### 1.3 安装 Maven 3.9+

```bash
# 使用 SDKMAN（推荐）
sdk install maven

# 或 Ubuntu / Debian
sudo apt install -y maven

# 验证
mvn -v
```

### 1.4 安装 Node.js 20+

前端构建需要 Node.js：

```bash
# 下载并安装 nvm：
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.3/install.sh | bash

# 代替重启 shell
\. "$HOME/.nvm/nvm.sh"

# 下载并安装 Node.js：
nvm install 24
```

### 1.5 安装 MariaDB 11

```bash
# Ubuntu / Debian（使用 MariaDB 官方仓库安装最新 11.8）
sudo apt install -y software-properties-common curl
curl -LsS https://dlm.mariadb.com/enterprise-release-helpers/mariadb_es_repo_setup | sudo bash -s -- --mariadb-server-version="mariadb-11.8"
sudo apt install -y mariadb-server mariadb-client

# CentOS / RHEL
sudo dnf install -y mariadb-server mariadb

# 启动并设置开机自启
sudo systemctl enable --now mariadb

# 安全初始化
sudo mariadb-secure-installation
```

> **可选**：本项目部分表支持 RocksDB 存储引擎以获得更好的性能。如需启用，安装 RocksDB 插件：
> ```bash
> sudo apt install -y mariadb-plugin-rocksdb
> echo -e "[mysqld]\nplugin_load_add=rocksdb=ha_rocksdb.so" | sudo tee /etc/mysql/mariadb.conf.d/rocksdb.cnf
> sudo systemctl restart mariadb
> sudo mariadb -e "SHOW ENGINES;" | grep -i rocksdb
> ```
> 未安装 RocksDB 也可正常运行，只需在导入 SQL 时使用 `poetry_old.sql`（全部使用 InnoDB 引擎）。

### 1.6 安装 Redis 7

```bash
# Ubuntu / Debian
curl -fsSL https://packages.redis.io/gpg | sudo gpg --dearmor -o /usr/share/keyrings/redis-archive-keyring.gpg
sudo chmod 644 /usr/share/keyrings/redis-archive-keyring.gpg
echo "deb [signed-by=/usr/share/keyrings/redis-archive-keyring.gpg] https://packages.redis.io/deb $(lsb_release -cs) main" | sudo tee /etc/apt/sources.list.d/redis.list
sudo apt-get update
sudo apt-get install redis

# CentOS / RHEL
sudo yum install redis
sudo systemctl enable redis
sudo systemctl start redis
```

配置 Redis 密码：

```bash
# 编辑 Redis 配置
sudo nano /etc/redis/redis.conf

# 找到 # requirepass，取消注释并设置密码
requirepass your_redis_password

# 重启 Redis
sudo systemctl restart redis-server
```

### 1.7 安装 Nginx

```bash
# Ubuntu / Debian
sudo apt install -y nginx

# CentOS / RHEL
sudo dnf install -y nginx

# 启动并设置开机自启
sudo systemctl enable --now nginx
```

### 1.8 安装运行时工具依赖

后端运行时会用到健康检查工具、媒体转换器、WebP 工具和 `cn-font-split`。Node.js/npm 已在上一步安装；`cn-font-split` 依赖需要项目代码，后面部署 JAR 时会安装到 `/opt/poetize/split_font`。

```bash
# Ubuntu / Debian
sudo apt install -y curl netcat-openbsd ffmpeg webp

# CentOS / RHEL
sudo dnf install -y epel-release curl nmap-ncat
sudo dnf install -y https://mirrors.rpmfusion.org/free/el/rpmfusion-free-release-$(rpm -E %rhel).noarch.rpm
sudo dnf install -y ffmpeg libwebp-tools

# 验证
curl --version
command -v nc || command -v ncat
ffmpeg -version
cwebp -version
dwebp -version
```

## 2. 初始化数据库

### 2.1 创建数据库和用户

```bash
sudo mariadb -u root -p
```

```sql
-- 创建数据库（使用 utf8mb4 编码）
CREATE DATABASE poetize CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

-- 创建用户并授权
CREATE USER 'poetize'@'localhost' IDENTIFIED BY 'your_db_password';
GRANT ALL PRIVILEGES ON poetize.* TO 'poetize'@'localhost';
FLUSH PRIVILEGES;
EXIT;
```

### 2.2 导入初始化 SQL

```bash
# 克隆项目（如果还没有）
git clone https://github.com/LeapYa/awesome-poetize-open.git
cd awesome-poetize-open

# 导入初始化 SQL（首次安装只需导入这一个文件）
mariadb -u poetize -p poetize < poetize-server/sql/poetry_old.sql
# 如果已安装 RocksDB 引擎，可使用 poetry.sql（history_info 表使用 RocksDB 引擎）
# mariadb -u poetize -p poetize < poetize-server/sql/poetry.sql
```

> **说明**：`poetize-server/sql/` 目录下的其他时间戳 SQL 文件（如 `202507220125.sql`）是**增量升级脚本**，仅在从旧版本升级时使用，首次安装无需导入。

### 4.3 配置 systemd 守护进程

创建 systemd 服务文件实现开机自启和后台运行（环境变量请根据你个人的实际配置修改）：

```bash
sudo tee /etc/systemd/system/poetize.service > /dev/null << 'EOF'
[Unit]
Description=POETIZE Blog Backend
After=network.target mariadb.service redis-server.service
Requires=mariadb.service redis-server.service

[Service]
Type=simple
# Ubuntu/Debian 使用 www-data，CentOS/RHEL 改为 nginx 或 root
User=www-data
Group=www-data
WorkingDirectory=/opt/poetize
ExecStart=/usr/bin/java \
  --enable-preview \
  -Xmx1024m -Xms512m \
  -XX:MaxMetaspaceSize=256m \
  -XX:+UseZGC \
  -XX:+ExitOnOutOfMemoryError \
  -jar /opt/poetize/poetize-server-exec.jar
Restart=on-failure
RestartSec=10

# 环境变量（根据你个人的实际配置修改）
# ==================================================
# 数据库连接（根据实际数据库类型修改 URL）
# MariaDB: jdbc:mariadb://localhost:3306/poetize?useUnicode=true&characterEncoding=utf-8&serverTimezone=Asia/Shanghai
# MySQL:   jdbc:mysql://localhost:3306/poetize?useUnicode=true&characterEncoding=utf-8&serverTimezone=Asia/Shanghai
Environment=SPRING_DATASOURCE_URL=jdbc:mariadb://localhost:3306/poetize?useUnicode=true&characterEncoding=utf-8&serverTimezone=Asia/Shanghai
Environment=SPRING_DATASOURCE_USERNAME=poetize
Environment=SPRING_DATASOURCE_PASSWORD=your_db_password

# Redis 连接
Environment=SPRING_REDIS_HOST=localhost
Environment=SPRING_REDIS_PORT=6379
Environment=SPRING_REDIS_PASSWORD=your_redis_password

# 站点配置
Environment=SITE_URL=http://your-domain.com

# 文件上传与预渲染目录
Environment=LOCAL_UPLOADURL=/var/www/uploads/
Environment=PRERENDER_TEMPLATE_PATH=/var/www/poetize/index.html
Environment=PRERENDER_OUTPUT_ROOT=/var/www/poetize/prerender
Environment=PRERENDER_ADMIN_TEMPLATE_PATH=/var/www/admin/index.html
Environment=PRERENDER_ADMIN_OUTPUT_ROOT=/var/www/admin/prerender

# 前端AES密钥（前端逆向可被看到）
Environment=POETIZE_AES_KEY=sarasarasarasara
Environment=TOKEN_SECRET_KEY=your_super_secure_random_key_here_at_least_32_chars
# ==================================================

[Install]
WantedBy=multi-user.target
EOF
```

## 5. 配置 Nginx 反向代理

### 5.1 创建 Nginx 配置

> **⚠️ 重要**：以下配置中的 `your-domain.com` 需要替换为你自己的域名。如果暂时没有域名，可以先用服务器 IP 或 `localhost` 代替。

```bash
sudo tee /etc/nginx/sites-available/poetize > /dev/null << 'NGINX_CONF'
server {
    listen 80;
    # ⬇️ 替换为你自己的域名
    server_name your-domain.com www.your-domain.com;
    charset utf-8;

    # 安全头
    add_header X-Content-Type-Options "nosniff" always;
    add_header X-Frame-Options "SAMEORIGIN" always;
    add_header X-XSS-Protection "1; mode=block" always;

    # 请求大小限制
    client_max_body_size 10M;

    # gzip压缩，如果需要Brotli压缩自行编译并添加相关代码
    gzip on;
    gzip_types text/plain text/css application/json application/javascript text/xml application/xml;
    gzip_min_length 256;

    # ===== 后台管理前端 =====
    location ^~ /admin/assets/ {
        alias /var/www/admin/assets/;
        expires 30d;
    }

    location ^~ /admin {
        alias /var/www/admin;
        index index.html;
        try_files $uri $uri/ /prerender/index.html @admin_fallback;
    }

    location = /admin/index.html {
        root /var/www;
        try_files /admin/prerender/index.html /admin/index.html =404;
        expires -1;
        add_header Cache-Control "no-store, no-cache, must-revalidate";
    }

    location @admin_fallback {
        root /var/www;
        try_files /admin/prerender/index.html /admin/index.html =404;
    }

    # ===== API 反向代理 =====
    location ^~ /api/ {
        proxy_pass http://127.0.0.1:8081/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_read_timeout 900s;
    }

    # Java后端用户相关 API
    location ~ ^/user/(login|register|logout|updateUserInfo|getCode|getCodeForBind|updateUserSecretInfo|bindingUserSecretInfo|getUserInfo|listUser|saveUser|updatePassword|updateAdminInfo|deleteUsers|getAdminUserInfo|updateAdminConfig) {
        proxy_pass http://127.0.0.1:8081;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    # OAuth 路由
    location ^~ /login/ {
        rewrite ^/login/(.*)$ /oauth/login/$1 break;
        proxy_pass http://127.0.0.1:8081;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    location ^~ /callback/ {
        rewrite ^/callback/(.*)$ /oauth/callback/$1 break;
        proxy_pass http://127.0.0.1:8081;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    # WebSocket（聊天室）
    location ^~ /ws/im {
        proxy_pass http://127.0.0.1:8081/ws/im;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_read_timeout 600s;
    }

    # SEO 相关
    location = /manifest.json {
        proxy_pass http://127.0.0.1:8081/seo/manifest.json;
    }
    location = /robots.txt {
        proxy_pass http://127.0.0.1:8081/seo/robots.txt;
    }
    location = /favicon.ico {
        proxy_pass http://127.0.0.1:8081/seo/favicon.ico;
    }

    # 静态资源（上传的文件）
    location /static {
        alias /var/www/uploads;
        try_files $uri @fallback_static;
        expires 30d;
        add_header Cache-Control "public, no-transform";
    }
    location @fallback_static {
        root /var/www/poetize;
        try_files /static$uri =404;
    }

    # 聊天室静态资源
    location /im/static/ {
        alias /var/www/poetize/static/;
        expires 30d;
        add_header Cache-Control "public, no-transform";
    }

    # ===== 安全防护 =====

    # 防止目录遍历攻击
    location ~* \.\./  {
        return 403;
    }

    # 禁止访问隐藏文件（排除 .well-known 以支持 SSL 证书验证）
    location ~ /\.(?!well-known/) {
        return 403;
    }

    # 禁止访问敏感文件类型
    location ~* \.(htaccess|htpasswd|env|config|ini|log|sql|bak|backup|old|tmp|swp|swo)$ {
        return 403;
    }

    # ===== SEO 预渲染页面（纯 Nginx 版本）=====
    #
    # 优先读取 Java 后端生成的 prerender 静态 HTML。
    # 如果没有生成对应预渲染文件，则回退到 Vue SPA。
    location = / {
        root /var/www/poetize;
        try_files /prerender/home/index.html @spa_fallback;
    }

    location ~ ^/article/([a-zA-Z-]+)/([0-9]+)$ {
        root /var/www/poetize;
        try_files /prerender/article/$2/index-$1.html /prerender/article/$2/index.html @spa_fallback;
    }

    location ~ ^/article/([0-9]+)$ {
        root /var/www/poetize;
        try_files /prerender/article/$1/index.html @spa_fallback;
    }

    location = /sort {
        root /var/www/poetize;
        try_files /prerender/sort/index.html @spa_fallback;
    }

    location ~ ^/sort/([0-9]+)$ {
        root /var/www/poetize;
        try_files /prerender/sort/$1/$arg_labelId/index.html /prerender/sort/$1/index.html @spa_fallback;
    }

    location @spa_fallback {
        root /var/www/poetize;
        try_files $uri $uri/ /index.html;
    }

    # ===== 主站前端（SPA 回退） =====
    location / {
        root /var/www/poetize;
        index index.html;
        try_files $uri $uri/ /index.html;

        location = /index.html {
            expires -1;
            add_header Cache-Control "no-store, no-cache, must-revalidate";
        }
    }

    # Let's Encrypt 验证
    location /.well-known/acme-challenge/ {
        root /var/www/html;
    }
}
NGINX_CONF
```

## 常见问题

### Q: 启动后端提示端口已被占用

```bash
# 查找占用 8081 端口的进程
sudo lsof -i :8081
# 杀掉该进程
sudo kill -9 <PID>
```

### Q: Nginx 提示 502 Bad Gateway

检查后端是否正常运行：

```bash
sudo systemctl status poetize
curl http://localhost:8081/actuator/health
```

### Q: 数据库连接失败

```bash
# 确认 MariaDB 运行状态
sudo systemctl status mariadb

# 测试连接
mariadb -u poetize -p -h localhost poetize -e "SELECT 1;"
```

### Q: Redis 连接超时

```bash
# 确认 Redis 运行状态
sudo systemctl status redis-server   # CentOS 上服务名为 redis

# 测试连接
redis-cli -a your_redis_password ping
```

### Q: 内存不足

如果服务器内存只有 2GB，可以调小 JVM 参数：

```bash
# 编辑 systemd 配置
sudo systemctl edit poetize

# 添加以下内容
[Service]
Environment=JAVA_OPTS=-Xmx512m -Xms256m -XX:+UseZGC
```
